This interactive model demonstrates the evolution of temperature under changing thermal and environmental parameters.

Adjust the parameters above to observe how the temperature response changes in real time.

Parameters

  • fmin: Initial temperature (200–500 K)
  • fmax: Final temperature (300–2000 K)
  • ts: Transition time (0–600 s)
  • m: Smoothness parameter (0.001–0.1)
  • k: Thermal conductivity (0.1–10 W/m·K)
  • Tamb: Ambient temperature (200–500 K)
  • h: Convection coefficient (0–200 W/m²·K)
  • t: Current time (0–600 s)
